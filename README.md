# Video to Roblox R15

## Project Overview
This project aims to convert video files into 3D models for Roblox R15 characters, enabling users to incorporate video content into their Roblox games. It streamlines the process of creating animations and content inspired by various video sources.

## Features
- Convert various video formats (e.g. MP4, AVI) into animations compatible with Roblox R15.
- Customizable export settings for optimizing performance in Roblox games.
- Built-in preview functionality to visualize the animations before exporting.
- Easy integration with Roblox Studio for seamless workflow.

## Tech Stack
- **Programming Language:** Python
- **Libraries Used:** OpenCV, NumPy, Pygame
- **Roblox API** for character manipulation and animation
- **FFmpeg** for video processing and conversion

## Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/ROYGBPJ/video-to-roblox-r15.git
   ```
2. Navigate to the project directory:
   ```bash
   cd video-to-roblox-r15
   ```
3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Ensure you have FFmpeg installed on your machine. You can download it from [FFmpeg's official site](https://ffmpeg.org/download.html).

## Usage Instructions
1. Run the application:
   ```bash
   python main.py
   ```
2. Load your video file using the GUI or command line interface.
3. Adjust the settings as needed for your export preferences.
4. Preview the animation to ensure it meets your expectations.
5. Export the animation, which will generate a file ready for use in Roblox.
6. Open Roblox Studio and import the generated animation for your R15 character.
